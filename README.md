## About

## Getting Started

To run the notebooks locally, make sure you have the following installed:

- Python 3.x
- Jupyter Notebook or JupyterLab
- Required libraries (NumPy, Matplotlib, etc.)

```bash
pip install jupyter numpy matplotlib
jupyter notebook
```
